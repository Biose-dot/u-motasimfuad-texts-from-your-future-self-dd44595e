Entry for the [make.fun](https://make.fun) bounty
[Texts From Your Future Self](https://make.fun/c/u-motasimfuad-texts-from-your-future-self-dd44595e).

A text from 2041: the robot vacuum has unionized, the houseplant you
never watered is now your landlord — and mom is still waiting on that
reply.

`main.py` (Python 3) writes the entry to `/output/entry.txt`:

> hey, it's me, you, from 2041. the robot vacuum unionized, the houseplant you never watered is now your landlord, and mom is still waiting on that reply.

Run it locally with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
